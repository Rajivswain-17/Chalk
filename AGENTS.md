# Chalk Project Rules

## 📖 Mandatory Knowledge Base (Read First!)
BEFORE searching or editing source files, you MUST read the project wiki:
1. `docs/wiki/index.md` — Overview map of the project.
2. Check specific wiki files (`database.md`, `api.md`, `components.md`) for your task.

Always update the relevant `docs/wiki/*.md` file whenever you create new tables, endpoints, or major components.
